# 05 · 行动结算功能方案

版本：v1.0（功能设计基线）
日期：2026-10-21
状态：用户同意保存本功能方向；仅设计，未实现或酒馆实测。具体规则、字段和实现选型仍待确定。

## 1. 定位与边界

处理玩家或 NPC 已明确决定尝试的一次行动：检查能否执行，按规则产生直接结果、代价和耗时。解决文字成功但状态未变、规则前后不一、重复消耗、随意编造代价等问题。

世界运转负责持续过程与后续影响；本模块负责具体行动的直接结算。总控安排调用，状态模块保存正式结果，叙述模块根据结果呈现正文。本模块不自行调度长任务、不直接写存档。

不替玩家选动作、接受交易或额外风险，不决定NPC意愿，不安排世界长期发展，不恢复已搁置的第三模块。说服理由充分不等于目标愿意，涉及人物决定的缺口明确交回总控。

## 2. 六项功能

### ACT-01 行动解析
将自然语言或按钮输入转换为行动者、目标、方法、执行范围、附加限制及必要前提。LLM处理自由表达，脚本检查对象和必需字段。

总控已负责任务调度；这里不再建立第二套规划器。保留“尽量不伤人”等限制。“看看能不能进去”不自动结算为潜入；重大歧义返回待澄清，不擅自补动作。

### ACT-02 条件检查
按有效状态与规则核对目标、距离、工具、材料、能力、身体、环境、冷却、封锁及步骤依赖。

返回可执行、不可执行及原因、附加条件或信息不足。已有条件明确否定的动作不靠随机机制突破；普通且确定的动作不强制掷骰。不能执行时是否已有准备成本须依据明确规则，不默认全扣或全退。

### ACT-03 规则选择
三种路径：明确规则由脚本计算；已定义不确定性按约定概率/对抗处理；规则空白由LLM提出依据清楚的有限裁定建议。

不默认全面数值化，不临时随意创造规则。重要空白交回总控决定澄清或暂停。可复用的新规则只是建议，不自动成为以后所有回合的正式规则。已选规则记录版本和适用范围。

### ACT-04 直接结果与代价
按玩法需要区分完全达成、部分达成、达成但有代价、未达成、中断；不要求所有场景使用全部类型。

输出材料/体力消耗、物品得失、直接伤势/位置变化、耗时及其他直接影响。代价源于规则和情境，不为戏剧性临时加罚。与世界模块约定直接影响边界，同一消耗不能两边重复计算。

### ACT-05 多步骤与中断
针对准备、加工、完成等阶段，列明已执行与未执行步骤、已消耗资源、半成品和可恢复条件。中断不一律全退或全损。

长行动由本模块提供阶段条件与结算建议，世界模块推进时间，总控安排后续处理。已提交阶段与本轮候选明确区分；不能把多轮过程当成一次可任意撤销的结算。阶段重复调用仍须去重。

### ACT-06 可追溯输出
记录行动标识、状态版本、规则依据、条件、结果、资源变化与未决项。随机机制若启用，由脚本产生且关联行动记录，不能由模型随口报点数。

同一次操作的重试复用已有有效结算记录，不能偷偷重抽；真正的新尝试、重生成、分支回退是否重抽待玩法合同明确。取消远端调用不等于取消已提交结果，沿用总控规则。

## 3. 脚本与LLM

脚本负责字段核对、确定性计算、已约定随机过程、资源合法性、版本与重复检查、结构化输出。
LLM负责自由输入理解、规则适用语义及规则空白的候选裁定。模型不直接执行代码、修改正式状态或改变规则权限。

结构合法不等于裁定公平，须用代表性场景测试。前提信息不足时不编造能力、距离、材料或NPC决定。

## 4. 工作流程

总控传入明确行动与有效状态
→ 解析目标、方法和限制
→ 检查执行前提
→ 选择已有规则或提出有界裁定建议
→ 计算直接结果、代价与耗时
→ 检查版本、结果一致性和重复结算
→ 返回总控。

总控协调状态模块提交；世界运转接收已确认结果处理后续影响；叙述根据核准候选生成正文，正式生效沿用总控提交合同。不能正文先写胜负再倒推数值配合。

失败或待澄清不继续拼凑成功结果。模型异常按总控预算处理，不另设无限重试。基于过期状态的候选不能覆盖新状态。

## 5. 交接建议

输入：任务/行动/尝试/会话/分支标识、起始状态版本、明确意图和限制、目标、有效规则及版本、相关资料、已结算阶段、预算。

输出：对应标识、已检查条件、规则与来源、成功/待澄清/失败等处理状态、行动结果、直接变更提案、耗时、阶段进度、随机记录引用（适用时）、依据和缺失。

处理成功不等于行动成功；一次正确计算的失败结果仍是正常返回。精确字段与接口未冻结，不声称酒馆已有这些API。

## 6. 示例与制作顺序

先验证：使用物品（条件、效果、消耗一致）；制作物品（材料、阶段、中断）；自由探索（自然语言解析，不增添玩家动作）。再按实际需求扩展战斗、修炼等规则，不预建完整数值系统。

例：玩家明确使用一份药物。检查持有、适用条件和规则，产生消耗与效果候选；失败原因若是无库存，不虚构消耗。若中断发生在药物已使用后，按规则记录已发生部分，不自动恢复库存。后续长时恢复由世界过程接续，不能重复施加即时效果。
