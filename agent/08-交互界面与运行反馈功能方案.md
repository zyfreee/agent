# 08 · 交互界面与运行反馈功能方案

版本：v1.0（功能设计基线）
日期：2026-10-21
状态：用户确认方向并授权保存。仅设计，未实现、未做酒馆实测；具体界面、字段与验收细节为建议。

## 1. 定位与边界

让玩家看清局面、提交操作、了解系统运行结果，并在出错时知道下一步。它是脚本与界面层，不是独立Agent，不为刷新面板额外调用模型。

优先复用用户选用插件的状态栏、任务面板与操作入口；已有功能满足需求时只做必要接入，不重建完整界面。插件、版本、界面承载方式尚未选定。

第七模块“状态与长期记忆”已从Agent系统中删除。这里从外部插件/数据库及核准结果读取数据，不另存一套世界状态，不重建记忆Agent。主生成环节负责正文；总控负责调度、提交协调和异常恢复。

## 2. 四项功能

### UI-01 查看当前局面

按需要展示玩家状态、当前地点及已知变化、任务/故事线进展、已知势力信息、长行动进度。

显示正式数据及来源版本，不让模型临时补数字。区分缺失、加载中、过期、读取失败与确实为空，不能把读取失败显示成背包为空或任务全部完成。展示范围受玩家知情限制，后台世界事实不默认公开。

只覆盖真实参与玩法且有有效数据的内容，不预建全部面板或模拟完整世界。

### UI-02 提供操作入口

候选入口包括查看任务、查看已知地图/地点、使用物品、开始/继续/中断行动，以及查询已知变化的原因。

按钮提交带对象和上下文的意图，经总控和相应模块处理，不绕过条件检查直接修改结果。自然语言输入继续保留，不把按钮作为唯一玩法。搁置的NPC独立聊天不借界面入口自动恢复。

防止连点形成重复执行；按钮所依据状态过期时重新核对，不对已经失效的任务或物品强行执行。具体防重机制与输入字段待实现时定义。

### UI-03 运行进度与异常反馈

显示实际任务状态：处理中、等待补充、已完成且保存、失败未生效、保存结果不确定待核对。不能把模型已返回文字视为正式保存成功。

失败时说明受影响范围、已确认生效部分与可执行下一步。有关联的变化不能仅凭界面隐藏错误而呈现成功。

重试和取消请求交给总控，停止等待不等于撤销已提交结果。重复点击不能重扣资源或重新抽取同次行动结果。只展示实际任务状态与必要依据，不展示模型内部思考，也不伪造百分比进度。

### UI-04 可选变化记录与作者调试

提供可折叠的本轮已知变化，例如任务目标更新、已知道路关闭、材料已扣除。记录关联正式结果，不把推测或待提交变化当作已发生。

作者调试视图可查看必要的模块输入/返回摘要、耗时、错误及记录标识；与玩家视图分开。后台秘密不混入玩家正文，不发送给不应知情的角色。敏感配置及凭证不显示。

隐藏按钮不等于信息隔离：玩家侧输出应在传入界面前按权限与知情范围筛选。若数据本身保存在玩家可检查的浏览器中，不承诺能抵抗其主动检查；本设计先保证正常游玩不意外泄露。

## 3. 不新增全局质量审查Agent

数据和输出结构由脚本检查；重复结算由总控与结算流程防护；世界变化依据由世界运转与玩家影响模块检查；正文事实与信息范围由主生成环节约束，必要时进行有针对性的复核。

不默认每轮再调用模型审查全部内容。脚本检查并不能证明所有语义均正确，后续仍需代表性场景与人工试玩。

## 4. 交接与工作流程

展示：读取当前会话/分支的有效数据 → 筛选可见范围 → 标识版本与读取状态 → 更新界面。

操作：玩家明确操作 → 提交意图与对象 → 总控处理 → 接收实际进度和提交结果 → 刷新正式数据 → 展示必要反馈。

输入建议：会话/分支、状态版本、可见数据、允许操作、任务状态、错误及正式变更记录。
输出建议：明确操作意图、对象标识、所依据版本、请求标识；不由UI直接生成行动成功结果。

快速切换聊天或分支后，旧请求返回不得覆盖新界面。具体事件、读取权限、按钮通信、刷新与生命周期API尚未核验，不声称现成插件天然支持全部能力。

## 5. 制作顺序建议

先检查既有插件能力，只补缺口。首个界面样本建议覆盖：一个状态展示、一个明确操作、一次成功反馈、一次失败反馈。再按游玩需要增加任务/地点信息与变化记录。

不在此阶段选择框架、视觉风格或大型控制台，不创建UI源码。若需要嵌入式界面，实施前进入相应界面与准确API专项设计，并分别验证浏览器显示和真实酒馆运行。

## 6. 待执行验收

1. 展示与正式数据一致，不编造数值。
2. 缺失、过期、读取失败和空数据可以区分。
3. 按钮与自然语言操作遵守相同结算和权限边界。
4. 重复点击不重复执行，过期对象不会误操作。
5. 处理中、已保存和保存失败不会混淆。
6. 取消或重试沿用总控规则，不伪称回滚成功。
7. 玩家界面与变化记录不泄露未知事实。
8. 作者调试信息不混入玩家正文或人物输入。
9. 切换聊天/分支后旧返回不污染当前视图。
10. 已有插件可满足功能时直接复用，未验证能力不伪称可用。

以上均未执行。后续区分静态数据测试、浏览器预览、真实酒馆验证与用户接受；文档保存不证明插件已接入。
