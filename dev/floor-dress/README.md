# 斗破 · 楼层美化（酒馆助手脚本版 v3 · 古卷装·沉浸版）

纯展示层的楼层装扮脚本：**不改聊天数据、不写变量、不动 agent 扩展、不改预设内容**。

## 已装到哪了

2026-11-10 已直接安装进酒馆的 **酒馆助手 → 脚本库**，脚本名「**斗破 · 楼层美化**」，
默认开启、只在斗破卡生效。酒馆重开、刷新都常驻。

## 它做五件事

1. **观世牌**（正文上方）：一张古卷整卡——时辰 / 所在 / 天气 / 大势四枚数据签，
   点牌头展开世界风云明细。数据来自聊天元数据 `doupo_agent_world`（只读）。
2. **开炉 · 备料**（玩家输入楼下）：三枚签——拾卷（原著卷宗注入）/ 翻忆（记忆召回）/
   过秤（行动结算）。正文动笔前的所有调用，一眼看完。数据来自 `doupo_agent_state`（只读）。
3. **收炉 · 落账**（正文下方）：四枚签——纳戒 / 记人 / 归档 / 留痕。正文写完后的所有账目。
   纳戒走楼层变量 `stat_data.斗破纳戒`，其余走聊天元数据（只读）。
4. **楼缝**：玩家楼与回复楼接缝一道鎏金细线，正中一粒会呼吸的异火（CSS 动画；
   系统开了「减少动态效果」就静止）。
5. **对话上色**：正文里成对的中文引号句子染主题色，带一层微光。
6. **正文章回排版**：段距拉开、段段首行缩进 2em、重点字染主题色、引文块当批注、
   正文横线变鎏金纹；正文书卷衬线字体（可关 `proseSerif`）。
7. **楼头与周边**：角色名牌鎏金渐字、头像斗气光环、主题色滚动条与划选区、
   输入框聚焦时的「玉牒」微光。
8. **炼字浮牌**：AI 生成期间，右下角浮出一枚呼吸的小火苗「炼字中 · 笔落如焰」，
   落笔完自动退场。
9. **整体窗景**：聊天窗整窗换装——窗口四周是深色案台，聊天柱是一整张卷轴面
   （米纸主题就是浅色纸面），楼块隐入纸面、玩家楼带一道淡印，顶栏与输入区随色；
   正文颜色随纸面自动反转（纸面上是深墨字）。预设的东西一概不碰。
   不想要整窗效果就把 `window` 关掉，楼层装扮仍在。
10. **斗破焰装**（`flavor` 开关）：案台暖光铺底、纸面烛光晕染与卷轴内框
    （不贴任何文字水印）、每层正文首字焰色下沉、卷尾落款
    「◆ 斗气大陆 · 第 X 天 · 所在 ◆」（世界账里的真实数据，压在正文末、收炉卡之前）。

## 长什么样（v2 古卷装）

- 卡片是「古卷」底：绢纹 + 双框 + 顶部一道鎏金光梁 + 四角斗拱饰角；
- 印是实心「盖下去」的印（暗金主题鎏金印、米纸主题朱印）；
- 数据签是玉牌形，前缀一粒菱形火屑；明细行是竹简一样的短行；
- 观世牌右侧竖排「斗气大陆」水印；
- 卡片入场有 0.45s 浮起动效；标题鎏金渐字带微光。

配色自动跟随 agent 面板选的主题（暗金 / 玄铁 / 米纸）。

## 怎么关 / 怎么撤

- 临时关：酒馆助手 → 脚本库 → 「斗破 · 楼层美化」关掉开关；切一下聊天残留即消失。
- 彻底删：脚本库里删除该脚本即可。

## 回滚备份

`backup-tavern-helper-scripts-2026-11-10.json` 是安装前的脚本库全量备份；
要恢复就把 `script.scripts` 数组整个替换回备份里的内容。

## 注意

- **贴底跟随（v6.8）**：进聊天 / 换聊天 / 脚本重跑都会开启 12 秒「进门宽限」，视口钉在底部，
  楼层边渲染边按回去。宽限只有玩家真实手势（滚轮 / 触摸 / 翻页键）才会解除；
  脚本自己的贴底赋值带 stickFlash 标记，不会被误判成手势。
- **视口锁（v6.10，悬空根修）**：表情面板（#expression-wrapper，690px）等在文档尾部多出的
  占位高度会把 document 撑出可滚空白，浏览器原生焦点滚动滚进去后整个界面被顶上去半截，
  窗口下面露出案台底色——看起来就是「聊天悬在半空、底下是装饰」。
  v6.10 美化开启时给 html/body 加 doupo-vp-lock（overflow:hidden）+ 400ms 看门狗
  （window / html / body 三个滚动容器一起盯一起归零，overflow:hidden 的 body 仍可被
  程序性滚动，必须一并看住）。样式 id 改为 `doupo-floor-dress-style-69`、视口锁单独成
  `doupo-vp-lock-style` 元素每次 sync 重写——因为**角色卡里还嵌着一份旧版美化**
  （data.extensions.tavern_helper.scripts，同名旧 id bcc1c49c），它每次 sync 都会往
  旧样式 id 里刷旧 CSS；分开 id 后互不相干。卡内那份旧拷贝哪天想摘再手术。
- **agent 悬浮入口（v6.10 配套）**：host/style.css 里补回丢失的
  `.dai-root{position:fixed;0x0}` 与 `[hidden]` 规则——它 static 时在文档尾部占 23px，
  也是撑高 document 的帮凶。
- **输入区回归（v6.11）**：`body.doupo-blaze #sheld { position: relative }` 这条焰装规则
  覆盖了酒馆原版 `#sheld` 的 `absolute`（顶栏下、贴合窗口底），使它掉进文档流再吃一层
  原版 top 偏移，把输入框/发送键/左下按钮挤出窗口 30px。已去掉 position 覆盖，
  并用 `body.doupo-dress-page.doupo-blaze #sheld { position: absolute }` 钉回原版；
  同一规则 + 视口锁也写进 agent 扩展 `host/style.css` 做文件级保险
  （不依赖脚本库版本，旧页面回写设置也覆盖不掉，已实测能压住旧脚本的坏规则）。
- **卡内旧拷贝已摘除（2026-11-12 手术）**：角色卡
  `data.extensions.tavern_helper.scripts` 里嵌的旧版「斗破 · 楼层美化」（id bcc1c49c）
  通过 `/api/characters/merge-attributes`（数组整组替换，先备份
  `backup-card-embedded-scripts-2026-11-12.json`）摘除；卡内只留
  卡面脚本 / 纳戒变量结构 / MVU 三个正常脚本，样式互刷从此绝迹。
- 控制台 `__DPD_VERSION__` 可查版本（v6.11 = 上述全套）。
- 工作区 `agent/doupo-agent-ui/host/chat-overlays.js` 是另一套「扩展内置版」的同款功能，
  **从未部署**。哪天如果部署了带装扮开关的扩展版，二选一（关脚本或关扩展里的对应开关），
  否则楼层会挂两层。
- 脚本顶部 `CONFIG` 里可以逐项开关组件（strip=观世牌 / settle=开炉·备料 / post=收炉·落账 /
  dress=楼缝+对话上色；改完在脚本库里保存重开即可）。
