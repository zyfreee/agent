斗破苍穹

在这片大陆上，重新活一次。

斗气大陆没有魔法，只有斗气。从乌坦城的小家族，到中州的门阀与古族，所有的门都只为有实力的人开着。

你会带着不属于这个世界的记忆醒来，从一具少年人的身体开始。原著里的人各有各的路，他们不会停下来等你——你只是这片大陆上，多出来的一个变量。

这一版会跟着你走的东西

  • ·背后有个 Agent 在记账：纳戒里的家当、人物簿里的关系、世界自己推进的事，都记在档上。
  • ·原著设定从资料库里查，不是凭印象编。
  • ·你可以给自己一个身份，顺便交代故事从哪一刻开始。

需要的东西

  • ·SillyTavern 1.18 及以上版本太低时扩展清单不会加载
  • ·Tavern Helper（JS-Slash-Runner）没装的话这张卡面只能看，点不动
  • ·斗破同人 Agent 扩展（已启用）纳戒、人物簿、世界台账都靠它
  • ·本卡的世界书（已导入并挂上）没挂的话原著设定就查不到
  • ·一个能用的模型连接看右上角的连接状态
  • ·剧情资料库（可选，后面再加）不加也能玩，加了 Agent 查得更准
